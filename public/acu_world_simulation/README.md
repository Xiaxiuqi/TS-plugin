# 格林推演悬浮面板

独立于 `acu_visualizer_test` 的只读脚本。加载 `index.js` 时会自动加载同目录下的 `style.css`，并在宿主页面挂载悬浮球。

```js
import 'https://ts-plugin.pages.dev/acu_world_simulation/index.js';
```

本地预览：`tests/acu_visualizer_test/world-simulation.preview.html`。

重复导入时会移除上一个实例；也可调用 `window.ACUWorldSimulation?.destroy()` 手动卸载。

脚本在宿主消息更新、聊天切换或消息楼层重绘后读取格林推演资料，不进行定时轮询。更新的分类、条目与字段会高亮，悬浮球收起时也会提示新资料。面板的位置和尺寸在拖动、缩放后保存到浏览器本地存储。

设置中的“酒馆 QR 按钮（隐藏悬浮球）”默认关闭。开启后在酒馆 QR 栏添加临时的“格林推演”按钮，点击打开资料面板，并隐藏悬浮球；收起面板后可再次通过 QR 按钮打开。设置会保存。关闭设置或卸载脚本会移除按钮，不改动已有快捷回复。QR 栏不可用时保留悬浮球作为入口。

手机通过局域网 HTTP 访问、无法使用 Web Crypto 时，脚本会按需加载同目录 `vendor/sha256.mjs`，使用相同的 SHA-256 算法匹配数据库锚点，不跳过聊天或分支校验。部署时需一并上传 `vendor` 目录。该文件为 `@noble/hashes` 1.8.0 的独立构建，MIT 许可见 `vendor/LICENSE.noble-hashes`。标题栏同时支持鼠标与原生触屏拖动。

设置中的“注入后修复正文显示”默认关闭。开启后检测同一聊天的格林推演账本变化，延迟 1 秒调用一次酒馆助手的 `refreshOneMessage` 刷新账本所在楼层，不检查正文投影标签。延迟期间若账本再次变化，则从最新变化重新计时，合并为一次刷新。相同账本的重复重绘不会再次触发；聊天切换、关闭开关或卸载脚本时取消待执行的刷新。不进行定时轮询，不修改聊天记录或数据库脚本。
